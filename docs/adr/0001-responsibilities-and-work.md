# A standing responsibility does not implicitly create Work

The owner wants a personal secretary that investigates agreed developments without another request each time, while ordinary conversation remains separate from explicit Work. A responsibility therefore owns the standing agreement, and an investigation owns a bounded evidence-gathering attempt; neither is represented by a silently created Work item. This preserves useful background activity without turning every email or check into a task or treating creation approval as action authority. It costs an explicit investigation lifecycle and removal of the runner's current assumption that every turn has Work. Reusing Work for all activity would be simpler initially but would preserve the domain error OA-342 is intended to remove.

The owner accepted this architecture and its implementation sequence on 2 November 2026. OA-342 now enforces independent chat and explicit Work. This decision does not enable automatic Work creation, connect accounts or authorize deployment. An owner-selected creation opt-in, if later designed, remains separate from read-only investigation and subsequent action permissions.
