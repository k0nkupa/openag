## Implemented behavior

- Owner/full-only model status, explicit discovery and revision-checked save under `/bots/:id/model[/discover]`. Limited clients are refused; ordinary status reads do not launch adapters or contact model providers. Save performs no inference.
- Brain sheet supports Claude/Codex ACP, direct OpenAI/Anthropic, OpenRouter and local Ollama. Discovery uses current provider/account data or an isolated ACP session. Hosted choices are filtered for compatibility with the installed integration. Missing capability data remains unavailable rather than an invented control.
- Stored choices, administrator overrides, session acknowledgement and returned model identity are separate. Unsafe overrides are masked/refused; override changes affect configuration revisions. Reports retain provenance, room, session/turn and time. Earlier configurations are labelled stale, including in other connected tabs/devices.
- ACP model and effort selections are validated on session creation/resume. A switch closes only the selected bot's adapter and invalidates its room sessions; it preserves bot data and existing gate/MCP/environment restrictions. Probe and configuration requests have deadlines.
- Configuration operations exclude dependent execution across the bot. Incoming work is persisted before waiting, then re-reads the bot at execution admission. Pending approvals, questions, receipts and native calls without result evidence still block changes, including after cancellation or recovery dismissal. Harmless interruption history does not permanently lock settings.
- Provider-specific reasoning options reach installed Mastra transports. Anthropic thinking modes require provider support; a numeric budget requires reported output limits and compatible thinking support. Runtime output limits account for the installed Anthropic transport adding the thinking budget. OpenRouter effort and numeric budget cannot be selected together. Ollama revalidates selected thinking values before chat.
- Minimal redacted report metadata includes returned model, provider and safe warning summaries. A partial event index supports bot report lookup. Latest reports are selected per room/source before response limits, so one busy room cannot hide quieter rooms. Truncation across more than 100 room/source pairs is explicit.
- Forms preserve supported reasoning drafts on refresh and save failure, prevent concurrent submissions and reconcile an unconfirmed response by reading state without automatically resending it. Model choices can recover from a removed/unavailable saved model.
