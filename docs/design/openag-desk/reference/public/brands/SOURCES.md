# Brand logo sources

Downloaded 2026-10-31. All SVGs are served locally; no runtime CDN requests.

- GitHub, Gmail, Google Calendar, Slack, Linear: SVG Logos by Gil Barbara,
  via @iconify-json/logos 1.2.18 (CC0-1.0).
  https://github.com/gilbarbara/logos
  Icons: github-icon, google-gmail-2020, google-calendar-2020, slack-icon, linear-icon.
- Brave, Claude Code, Codex, Anthropic, OpenAI, Nebius, Ollama, Typesafe, OpenRouter:
  @lobehub/icons-static-svg 1.101.0 (MIT).
  https://github.com/lobehub/lobe-icons
  Icons: brave-color, claudecode-color, codex-color, anthropic, openai, nebius, ollama, typesafeai, openrouter.

Original SVG geometry and brand colours are retained. Monochrome marks adapt to
light/dark mode through CSS. The associated brand names and marks belong to their
respective owners. Bundled licence files cover the icon collections.
