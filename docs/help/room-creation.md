# Create a room

With Owner or Full access, use the plus beside **Rooms** in the redesigned sidebar. Enter a name, select existing agents and choose a lead from them. Names may repeat; each room has its own identity. Avatars and agent handles distinguish agents with the same display name. The searchable agent list has a fixed height and scrolls, so a large catalogue does not expand the sheet.

A named room with one agent is separate from that agent's direct chat. Creation starts no agent turn or Work and changes no proactive delivery destination. Limited devices cannot create rooms.

On an error, the sheet keeps the draft. If creation is uncertain, use **Check creation status** before retrying. Never assume a matching name proves that a room is the result of the submission. Drafts are kept for the current page session only.

To add existing agents later, open the room’s context panel, select **Room settings**, choose agents under **Add agents**, then select **Save room details**. Existing members stay checked. Owner or Full access is required. Rooms support up to 50 agents. Adding agents preserves the lead and history and starts no turn. You can choose a new member as lead after saving. Direct chats keep one agent.

Room deletion and member removal are unavailable. The classic fallback desk has no New room control. See docs/notes/room-creation.md for the authoritative behavior and limits.
