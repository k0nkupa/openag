# Existing conversation forks

The chat checkpoint and **Fork from here** control have been removed. The desk no longer offers checkpoint creation.

Existing forked conversations remain available as named rooms. Their saved visible transcript remains contextual data, grants no permissions and replays no earlier actions. Send a message to continue normally. Original conversations, attachments, approvals and execution receipts remain intact.

Existing attachment references still link back to the original conversation; reattach a file if the agent needs its contents. Removing the checkpoint control does not delete history, undo effects or change proactive delivery. No bot tool creates a fork. See `docs/notes/conversation-forks.md` for retained storage and compatibility behavior.
